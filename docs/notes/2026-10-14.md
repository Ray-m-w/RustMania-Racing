   modelled (mean change < 0.1 step); (c) measurement: the oracle's VRAM
   shots expand 5 -> 8 bits as c << 3 (max 248) vs the port's c*255/31, so
   the means are compared on the 5-bit scale. Not a cause: the animated
   strips (the "misalignment" was the vram_peek hex read little-endian; read
   high byte first all 26 reads of strip 0x19 match a decoded frame exactly).
   Method: analysis/s6/water/means.py (open-water mask b > 100, r < 70,
   g < 60 at 512x240, --faithful-view, --replay-capture race3e). 5-bit
   means, oracle / before / now: VB 800 4.59/3.36/16.34, 5.29/3.47/17.55,
   4.97/2.90/16.65; VB 3350 4.86/2.95/16.96, 5.29/3.34/17.99,
   4.96/2.75/17.04. Side by side analysis/s6/water/sbs_water_q5.png.
