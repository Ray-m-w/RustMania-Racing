# Rendering: differences ledger (port/crates/mr-bevy)

What the Bevy presentation does differently from the game's renderer, and why.
Simulation state is never derived from rendering (ADR-0002 split).

| Area | The game | mr-bevy | Why / status |
|---|---|---|---|
| Rasterisation | GPU, affine texture mapping, 15-bit colour, dithering | GPU via wgpu, perspective-correct, 8-bit sRGB, no dither; MSAA (`msaa`, default 4x, off/2/4/8) on all three cameras | modern presentation; texel choice and colour modulation (texel*rgb/128) match |
| Texture filtering | point sampling, colour 0 transparent | `texture_filter = smooth` (default): bilinear + 5 mip levels (256..16, a 2x2 box chain never mixes two 64x64 tiles of a page at those levels) + anisotropy 16; transparent texels take their opaque neighbours' colour (6 dilation passes) and mips average in linear light weighted by alpha, so cut-out edges have no dark fringe; opaque cut-out scenery uses alpha to coverage (Mask(0.5) without MSAA). `nearest` = point sampling + Mask(0.5) as the game. The HUD is always point-sampled (UVs inset 1/4 texel against MSAA edge extrapolation) | Session 5; one switch to the original look (`faithful_view` sets every view option faithful) |
| Draw order | ordering tables, no depth buffer | depth buffer; layer 1 (far stand-ins) + sky drawn in a first camera pass, layer 0 + kart over it with a fresh depth buffer; layer-0 "ground" list depth-biased under the near list | reproduces the OT layering that matters on DOCK (DAT.md); exact OT order within a layer is not reproduced |
| Near-polygon subdivision (layer 0) | near polygons split 2x2 with interpolated UV/colour | not done | only affects affine warp, unnecessary with perspective-correct mapping |
| Texture LOD (slots 0..3) | UVs >> 1 / >> 2 by depth (decimated copies) | stored UVs always (LOD 0) | LOD 0 is what the game shows up close; distant ground is sharper than the original |
| Per-frame object selection | visibility stream + cull | default: the whole course every frame: every layer-0 object whose visibility bit is set at some node (19 of 589 DOCK objects never are: small ground pieces, hidden) except the 11 special-slot item objects (parked off the course; items are drawn by effects.rs), plus layer-1 objects that are real backdrop (less than 50% of their area within ~192 DAT units of layer-0 surfaces: on DOCK only object 767, the 0x89 backdrop shell); the other 242 layer-1 stand-ins duplicate layer-0 scenery and are dropped; the banner's 0x2000 cull is off too. `faithful_draw_distance = true`: the game's rule (Dat::drawn), exact | owner decision 2026-10-13 (pop-in); `scene::classify_layers`, `--layer-report`; evidence analysis/s5/drawdist |
| Animated textures (RAW type 0x22) | FUN_8007A9DC -> FUN_800311AC copies one frame per strip into VRAM every race frame (frame from DAT_800B0D90; strip 0x1E from DAT_800B07D4) | same copies (animtex.rs, effects.md), cached page images rewritten in place | strip 0x1E's counter DAT_800B07D4 is approximated by the frame counter (its phase at race load is not modelled) |
| Kart/driver parts | per-part matrices from the kart record | same rules (kartmodel.rs, MDL.md) | exact for the parts; depth-cue colour factors (+0x414..) not applied |
| Lighting / fog | per-vertex colours, depth cue | per-vertex colours only (default); `lighting = enhanced` prototype: linear distance haze on the main pass from 40 to 650 Bevy units (5k..83k DAT units) up to 60% toward the sky dome's horizon colour (AXE vertices within 10 deg of the horizon); sky and far backdrop unfogged | depth cue not ported; enhanced look awaits the owner (analysis/s5/lighting) |
| Resolution / aspect | 512x240, 4:3 | window size (default 1600x900); `aspect = native` (default): vertical FOV 73.7 deg kept, horizontal widened with the window (90 deg at 4:3, 106 at 16:9); narrower than 4:3 is letterboxed; `aspect = 4:3`: pillarboxed viewport on every camera | Session 5 |
| HUD placement | 512x240 screen | 240 game lines high, width = 512 x (aspect / (4/3)); primitives grouped into elements (boxes within 6 px, transitively) and an element in the left 30% moves left by half the extra width, in the right 30% right (item slots, lap, meter, minimap), the rest stays centred (place, arrow, timer, banners, countdown, results) | as the recomp package's auto_ui_squash (game.toml [widescreen]): native proportions pinned to thirds |
| Track objects outside DAT scenery | start/finish banner: cloth from DAT chunk 9 (FUN_800351e8, animated by FUN_80035004); kart shadows (0x800C8B38 list, FUN_8002ADA8); pickups (0x800E1B70 boxes, 0x800E2370 tokens, FUN_8007E21C); particles 0x800E0C20 (FUN_80010E90), sparks 0x800B4540, projectiles 0x800DDC50, via the 0x800DF688 billboard batch (effects.md) | banner drawn with the game's geometry, animation, UVs, shading and 0x2000 cull (scene::ObjectsPlugin, DAT.md "Start/finish banner"); cloth phase for replays taken from the lap1 savestate; particles, sparks, pickups and projectiles drawn by effects.rs (below) | banner exact to the GTE vertex; the phase is power-on dependent in the game |
| Kart shadows | one FT4 per kart from the kart record (FUN_8003E91C tail, FUN_8003E59C ground matrix, FUN_8003E3A0), slot 0x14 kart-silhouette tile at kart+0x16C/0x16D, subtractive blend (ABR 2), faded from view z 0x1000 to 0x1800, +-0x30000 cull, back faces culled (FUN_8002ADA8); pickup shadows from the same list (entries 6.., FUN_8007B800) | same records (kartshadow.rs, exact on 17/18 oracle records; pickupshadow.rs, 76/76 exact), drawn by the effects pass (psxfx.rs) with exact B - F on the gamma-encoded frame, depth-tested with the ground under them exempt; interpolated like the kart | Session 5: the Session 4 alpha approximation is gone |
| HUD | position, lap, timer, minimap, items, banners | everything of the 1-player race HUD (hud.md, primitives exact vs GP0 on 345 frames); drawn as quads / triangles / 1-pixel lines over the 3D in a 512x240 ortho view; modulation in linear space as (c/128)^2.2; abr 3 (B+F/4) as additive at 1/4, abr 2 as a 50% blend; the texel STP bit is ignored (whole primitive semi) | lines are quads one game pixel wide; special-move icons use character texture slots 9/0xA that the course RAW does not load (wrong texels until the character textures are decoded) |
| AI karts, items, effects (stars, sparks, skid marks, shadow) | drawn; far karts (LOD +0x4B4 >= 0x10) as seven-ball impostors (FUN_8007D660), no model | AI karts drawn (Session 3); particles, sparks, pickups, projectiles, special glow, all FUN_80037B80 status effects (inline billboards + the five FUN_800313BC shapes, kartfx.rs), the flat list 0x800C84B8 (splash rings, one-frame skid quads; sim exact), pickup shadows; the impostor only with `faithful_draw_distance` (which hides the model), else full models at every distance | Session 5 (effects.md); the status shapes are [CODE] only (no oracle race with character specials) |
| Billboards (particles, pickups, projectiles) | GTE: view-space quad of half size (w, h) world>>5 units, x stretched 1.6 (0x1999) or 1.5 when rotated for the 512-pixel screen, rotated in the screen plane; ordering-table depth OTZ * 4 + bias * 4; the ground list drawn first | camera-facing quads at the point (no pull toward the eye), depth-tested against the scene; an occluder that is upward-facing ground below the sprite and within twice its size does not hide it (the game's ground-first order); OT bias kept as a depth pull (OTZ = z / 4 assumed); anchor 4 honoured; ground-flat particles (0x10) flat in world x/z | Session 5 sprite depth (`fx_depth_test`); rotated-sprite 1.5 stretch not reproduced; where the game's OT and a depth test disagree (large polygons, sprites partly inside near-list geometry) the port follows depth |
| Semi-transparency (effects) | ABR 0..3 on the 15-bit framebuffer values (gamma), texel STP bit selects blended texels | effects pass (psxfx.rs): the frame copied to a non-sRGB texture of the same bytes, fixed-function B/2+F/2, B+F, B-F, B+F/4 on it, STP honoured, written back to every MSAA sample | Session 5, `fx_blend = psx` (default) / `linear`; error: 8-bit channels (no 15-bit quantisation, no dither). Explosion at VB 3010 (region mean RGB): oracle 184/144/97, port 185/140/86 (Session 4: 169/122/76; linear: 162/114/68). Scene semi-transparent polygons (psxmesh, E) and the HUD still blend in linear space |
| Spark streaks | LineG2, 1 pixel, additive, black to colour | additive gouraud quads ~1 game pixel wide facing the camera, through the effects pass (exact B + F) | width by distance approximated |
| Type-2 projectile view frame | ratan2 (PSYQ table) | f64 atan2 rounded to 4096 units | may pick the neighbouring view frame at a boundary |
| Frame rate | 30 Hz logic; 20 Hz in heavy scenes | 30 Hz logic always, rendering interpolated at display rate | intentional: the port never slows down (physics ledger) |
