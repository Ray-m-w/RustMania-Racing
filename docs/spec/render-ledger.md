# Rendering: differences ledger (port/crates/mr-bevy)

What the Bevy presentation does differently from the game's renderer, and why.
Simulation state is never derived from rendering (ADR-0002 split).

| Area | The game | mr-bevy | Why / status |
|---|---|---|---|
| Frame clear | GP0 fill (0, 19, 95) on DOCK each race frame | ClearColor = the same as the 15-bit framebuffer stores it: (0, 2, 11) -> (0, 16, 90) (`psxfx::psx_fill`) | Session 5 finishing (was a made-up lavender, visible under the additive water); Session 6: quantised like the GPU's fill |
| Rasterisation | GPU, affine texture mapping, 15-bit colour, dithering | GPU via wgpu, perspective-correct, 8-bit sRGB (the effects pass's output stored 15-bit, Session 6), no dither; MSAA (`msaa`, default 4x, off/2/4/8) on all three cameras | modern presentation; texel choice and colour modulation (texel*rgb/128) match |
| Texture filtering | point sampling, colour 0 transparent | `texture_filter = smooth` (default): bilinear + 5 mip levels (256..16, a 2x2 box chain never mixes two 64x64 tiles of a page at those levels) + anisotropy 16; transparent texels take their opaque neighbours' colour (6 dilation passes) and mips average in linear light weighted by alpha, so cut-out edges have no dark fringe; opaque cut-out scenery uses alpha to coverage (Mask(0.5) without MSAA). `nearest` = point sampling + Mask(0.5) as the game. The HUD is always point-sampled (UVs inset 1/4 texel against MSAA edge extrapolation) | Session 5; one switch to the original look (`faithful_view` sets every view option faithful) |
| Draw order | ordering tables, no depth buffer | depth buffer; layer 1 (far stand-ins) + sky drawn in a first camera pass, layer 0 + kart over it with a fresh depth buffer; layer-0 "ground" list depth-biased under the near list | reproduces the OT layering that matters on DOCK (DAT.md); exact OT order within a layer is not reproduced Session 6 visual check: the -2000 depth bias of the ground list did nothing measurable (a kart 130 DAT units under GHOST's drawn ground was hidden); every layer-0 object now writes its depth pushed 4 * its OT bias view units back (next row) |
