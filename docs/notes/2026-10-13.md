What was done
- settings.rs: `Settings` resource (defaults in `KNOWN` <- `settings.txt` beside
  the exe or `--settings PATH` <- `--set k=v` / `--key [v]`); API posted in
  SESSION-5-coord.md early. Keys: faithful_view (preset), faithful_draw_distance,
  aspect, msaa, texture_filter, lighting, resolution, fullscreen, vsync.
- Draw distance: `scene::classify_layers` samples every DAT surface (96-unit
  step) and measures, per layer-1 object, the area within ~192 DAT units of a
  layer-0 surface. DOCK: 242 of 243 layer-1 objects are >= 70% covered
  (stand-ins: 231 at 100%); only object 767 (flags 0xC9, the 0x89 backdrop
  shell, radius 16185) is 36% covered = real backdrop, kept in the far pass.
  Layer 0: 19 objects never have their visibility bit at any node (small ground
  pieces, mostly y ~ 2991, i.e. below the deck) and the 11 special-slot item
  objects are parked at (72k, 79k) off the course: both left out. Everything
  else drawn every frame; the banner's 0x2000 cull is off too. Faithful mode
  = the old select_objects path unchanged (Dat::drawn tests unchanged).
  Camera far = 2000 Bevy units (256k DAT units) covers DOCK (~150k across).
  Evidence: analysis/s5/drawdist/{faithful,full,sbs}_{500..2000}.png (autopilot,
  1920x1080): faithful shows the coarse untextured stand-ins with pickups
  floating in front of them; full shows the textured deck and walls.
- Widescreen: cameras keep vertical FOV 73.7 deg; `aspect = 4:3` (or a window
  narrower than 4:3) puts a centred 4:3 Viewport on all three cameras. HUD:
  ortho width 512 x aspect/(4/3); primitives clustered into elements (6 px)
  and pinned left (right edge < 30%), right (left edge > 70%) or centre, like
  the recomp's auto_ui_squash. analysis/s5/t700_full.png (16:9),
  t700_full_43.png (4:3). No oracle run needed.
- MSAA: chase, far-pass and HUD cameras share `Settings::msaa()`; HUD sprite
  UVs inset 1/4 texel (MSAA evaluates edge pixels at the centre: thin lines of
  the neighbouring texel row appeared over the item slots / meter at 1080p).
- Texture filtering (vramtex.rs): smooth = bleed transparent texels from opaque
  neighbours, 5 alpha-weighted linear-light mips (tile-safe), trilinear +
  aniso 16, AlphaToCoverage cut-outs; nearest = the old path. HUD always
  nearest. Animated pages: the first version rebuilt whole pages and caused
  7-12 ms frame spikes (p95 7 ms); now only the changed 64-tiles are rebuilt
  (`smooth_region`, unit-tested equal to a full rebuild): spikes gone.
- Lighting prototype (lighting.rs): `lighting = enhanced` = linear distance
  haze 40..650 Bevy units up to 60% toward the AXE horizon colour, main pass
  only. Side by sides: analysis/s5/lighting/sbs_{800,1400,2000}.png (left
  faithful, right enhanced). NOT default: owner decides.

Performance (RTX 5090, autopilot race, vsync off, full draw distance, MSAA 4x,
smooth): 1920x1080 416 fps (p99 3.3 ms), 2560x1440 422 fps (p99 3.2 ms):
CPU-bound. MSAA off ~ same. (One earlier 66 fps run was contention with other
agents' builds; not reproducible.)
